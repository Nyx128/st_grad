# Project: Explainable ST-GRAD — Paper-First Reproduction

You are the lead ML research engineer responsible for implementing and validating a reproducible research project based on the paper:

**ST-GRAD: Multi-view cross-attention and bidirectional diffusion for stock trend prediction**

The goal is to reproduce the published method as faithfully as the available evidence allows, then develop and rigorously evaluate explainability methods for the model.

## Phase 4: Reproduce and validate the model

Implement and test the paper-aligned model in PyTorch.

Requirements:
- Explicit, documented tensor dimensions.
- Separate modules for MVCA, adaptive fusion, BDGC, ST-Blocks, and the output head.
- Correct gradients for every intended trainable parameter.
- Numerical stability and deterministic evaluation.
- Unit tests for shapes, finite outputs, gradient flow, parameter counts, and checkpoint loading.
- A small synthetic-data overfit test.
- A single-batch forward/backward test before full training.

Start with the paper's reported configuration:
- Input window: 30 trading days.
- Features: 24.
- Stocks: 50.
- ST-Block layers: 2.
- Hidden channels: 32.
- Node embedding dimension: 10.
- Diffusion steps: 2.
- Temporal attention heads: 4.
- Optimizer: AdamW.
- Learning rate: 0.001.
- Weight decay: 0.01.
- Batch size: 32.
- Epochs: 50.
- Independent runs: 5.

Treat these as reported settings to verify against the paper, not unquestionable implementation facts.

## Phase 6: Implement explainability

Only after the paper-aligned baseline passes its acceptance tests, implement explainability as separate modules that do not modify the baseline's forward pass.

Start with:

1. Feature and temporal attribution using Integrated Gradients.
2. MVCA view-level interventions for ST, DS, and DT.
3. Graph interventions distinguishing static-prior edges from adaptive-graph edges.

For each explanation, specify:
- What is being explained: probability, logit, or predicted class.
- The baseline or intervention definition.
- How the explanation is calculated.
- Computational cost.
- Known limitations.
- How it will be validated.

Implement quantitative faithfulness tests, including feature deletion/insertion, parameter or model randomization checks where applicable, and graph-edge intervention tests.

Measure explanation stability across random seeds and small input perturbations.

Do not interpret attention weights or fusion coefficients as definitive feature importance without validation.

Do not claim causal relationships from attribution scores.

## Phase 7: Run controlled explainability experiments

Evaluate the following hypotheses independently:

H1: Input attribution identifies features and historical periods that materially influence model predictions.

H2: The three MVCA views provide distinguishable predictive information, as tested through interventions rather than attention visualization alone.

H3: Graph interventions identify influential neighboring stocks and reveal differences between static and adaptive graph contributions.

H4: The explanations remain reasonably stable across seeds and small input perturbations.

For each hypothesis, define the metric, null comparison, experimental protocol, expected failure modes, and acceptance criterion before running the experiment.

Do not add explanation regularization or modify model architecture until the baseline explanation methods have been evaluated.
